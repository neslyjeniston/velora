# Velora – Daily Activity Tracker

Velora is a full-stack habit tracking and productivity application designed to help users build consistency, track progress, and reflect on personal growth.

## Features

* Secure user registration and login using JWT authentication
* Create and manage daily and weekly habits
* Track habit completions and maintain progress history
* Monthly reflection journaling with affirmations
* Persistent cloud storage using MongoDB
* Responsive and modern user interface
* Real-time habit statistics and progress tracking

## Tech Stack

### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS
* React Router

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* bcryptjs

## Key Functionalities

* User Authentication
* Habit Management
* Completion Tracking
* Monthly Reflections
* Progress Analytics
* Persistent Data Storage

Velora helps users stay accountable, build positive routines, and gain insights into their personal development journey.
